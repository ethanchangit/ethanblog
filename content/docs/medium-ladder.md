## 核心思想

讲故事时，媒介每升一级，读者就需要做更少的「脑内补全」：

```
L0 文字  →  想象
L1 图像  →  看见
L2 视频  →  在场
L3 交互  →  参与
```

**L3 不是「更炫的视频」，而是软件**——有状态、有输入、有反馈。用户的动作会改变故事世界的呈现。
