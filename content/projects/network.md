Network 是一款以**键盘为中心**设计的桌面笔记应用。

## 核心功能

- 卡片式库系统
- 高级键盘快捷键
- Markdown 支持（Tiptap）
- 标签组织
- PDF 与文档支持

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Electron, React, TypeScript |
| 存储 | 本地 SQLite + 云同步 |
| 构建 | electron-builder |
