- 这个软件如何存储笔记：它所有的内容都是 card，你的 card 存在 library 中，不需要考虑如何整理它们，创建就是创建了，不需要找地方放。

- whiteboard 核心功能：可以在这里使用 whiteboard 来当成一个 folder 去使用，相当于你的 folder 里的内容丢在一块画布上，可以连线，换颜色，写备注来进行整理。

- tag 核心功能：一个 database，目前只支持 table 和 kanban 两种样式，但足以用来整理一些同质性的内容，例如 meeting-note, blog 和 book-note

- chat & agent 核心功能：Heptabase 的几乎所有功能都是 agent 可操作的

- Highlight：可以读 pdf & webpage 并标注 highlight，而且可以将 readwise 中的 highlights 也导入进来，所有的 highlights 都是一张 highlight card，按 document 分组显示。
