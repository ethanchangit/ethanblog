这条研究线只问一个问题：**一张网页，能不能像房间一样对人做出反应？**
不是"更炫的动效"，也不是"更高的转化率"，而是内容本身对你的位置、你的动作、
你的停留做出回应——并且支配这些反应的规则，你看得见，也改得动。

## 调研先行

Ink & Switch 用十年时间沿着 local-first、可塑软件、可编程墨水、通用文档这几条线做研究。
他们的发布分两档：打磨过的 essay 面向外界，编号的 lab notebook 记录过程——
**过程本身就是产出**。你现在读的这条笔记，就是这套两档发布制在本站的第一次运转：
它有编号、挂在研究线下、发出去不回改，勘误写在下一篇。

<SideNote label="旁注">
  这条挂在页边的旁注也是新机制之一——抄自 Ink & Switch 的版式语言，
  零 JS，宽屏悬挂右页边，窄屏回落为你现在看到的插注块。
</SideNote>

Bret Victor 的 Realtalk/Dynamicland 把另一件事讲透了：计算应该是**可见的、实时的**，
行为由一条条声明式规则支配（Claim / When / Wish），规则摊在桌面上，
任何人都能拿起来读、改、组合。完整调研档案存在仓库的
`docs/research/ink-and-switch.md`，一万两千字，这里只留一句判断：
**网页继承不了 Realtalk 的身体和场所，但能继承它的软件灵魂——实时、可见、可改、可组合。**

## 页面即房间

Realtalk 的空间性看似无法迁移——我们没有那张桌子。但有一个诚实的对应物：
**页面即房间，视口即桌面，滚动即走动**。"当这段文字进入视野"和 Dynamicland 的
"当我上方有对象时"，是同构的空间谓词。

## 拆开看

Realtalk 的可见性原则说：程序印在物体上。本站的翻译是——每个媒介组件下面
自动出现一个「⌥ 源码」，展开就是这段组件调用在 MDX 里的原文，构建期自动注入，
作者零负担。往上翻，RuleGarden 下面就有一个；下面这个滑块组件也有：

<ParamSlider

源码不是附录，是媒介的一部分：**读者与拆解者之间，不该有一堵墙。**

## 这一批建了什么

盘点这条研究线第一批落地的机制，全部零新增 npm 依赖：

- **两档发布制**：`kind: notebook` + 研究线（`/threads`），五行 frontmatter 就能发一条笔记
- **论文式页面接口**：署名、摘要、目录、引用块、文末的"来聊"邮箱
- **SideNote 旁注** 与 **InteractiveDemo 的 poster 档**（视频先行、点击升级）
- **「拆开看」**：remark 插件构建期注入组件源码 disclosure
- **RuleGarden + RuleTarget**：第五媒介档位——可改写的规则
- **创作宪法 `docs/MEDIUM.md`**：任何 agent 读后都能把对话/文章转化为这种媒介

也有被砍掉的：fork 到沙箱、目录滚动高亮、规则链、规则持久化。
为什么砍，记在下一篇笔记《设计取舍》里——编号 #02，审阅后发布。

This thread asks one question: **can a web page respond to a person the way a room does?**
Not flashier motion, not higher conversion — the content itself answering to where you are, what you do, how long you stay — and the rules that govern those answers, readable and editable.

## Research first

Ink & Switch spent a decade along local-first, malleable software, programmable ink, and universal documents.
They publish in two gears: polished essays for the outside, numbered lab notebooks for the process —
**the process is the output**. The note you are reading is the first run of that two-gear system on this site:
numbered, hung on a thread, sent and not silently rewritten; errata go in the next note.

<SideNote label="Marginalia">
  This sidenote hanging in the margin is one of the new mechanisms — borrowed from Ink & Switch’s layout language,
  zero JS, hanging in the right margin on a wide screen, collapsing to an inset on a narrow one.
</SideNote>

Bret Victor’s Realtalk/Dynamicland made another point sharp: computation should be **visible and live**,
behavior governed by declarative rules (Claim / When / Wish), laid out on a table,
anyone able to pick them up, read them, change them, compose them. The full research file lives in
`docs/research/ink-and-switch.md`, twelve thousand words. One judgment here:
**a web page cannot inherit Realtalk’s body and place, but it can inherit the software soul — live, visible, editable, composable.**

## The page as a room

Realtalk’s spatiality looks untranslatable — we do not have that table. There is an honest counterpart:
**the page is a room, the viewport a desktop, scrolling is walking.** “When this text enters view” and Dynamicland’s
“when there is an object above me” are isomorphic spatial predicates.

## Take it apart

Realtalk’s visibility principle: the program is printed on the object. Our translation — under every media component
an “⌥ Source” appears, the actual MDX call, injected at build time, zero author work. Scroll up: there is one under RuleGarden; the slider below has one too:

<ParamSlider
  client:visible
  label="Number of objects in the room"
  paramKey="count"
  min={10}
  max={200}
  initial={60}
  viz="network"
  caption="A component that already existed in July 2026. New mechanisms are not picky — every media component gets “take it apart.”"
/>

Source is not an appendix. It is part of the medium: **there should be no wall between reader and disassembler.**

## What this batch built

The first mechanisms of the thread, all with zero new npm dependencies:

- **Two-gear publishing**: `kind: notebook` + threads (`/threads`); five lines of frontmatter to ship a note
- **Essay-style page interface**: byline, abstract, contents, citation, a “write me” mail at the end
- **SideNote** and **InteractiveDemo’s poster gear** (video first, click to upgrade)
- **“Take it apart”**: a remark plugin injects component source at build time
- **RuleGarden + RuleTarget**: the fifth media level — rules you can rewrite
- **A constitution in `docs/MEDIUM.md`**: any agent that reads it can turn a conversation or an essay into this medium

Cut: fork-to-sandbox, scroll-highlight on the TOC, rule chains, rule persistence.
