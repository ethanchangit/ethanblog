Network 是一款为重度键盘用户设计的桌面笔记应用——双手不离开键盘，完成从记录到组织的全部操作。

## 功能

- 卡片式笔记库系统
- 深度优化的键盘快捷键体系
- 基于 Tiptap 的 Markdown 编辑体验
- 标签化组织
- PDF 与文档支持

## 技术架构

- **前端**：Electron + React + TypeScript
- **存储**：本地 SQLite + 云同步
- **构建**：electron-builder
