这个网站本身就是一件作品——一个把文字、图像、音频、视频和**软件级交互**组织在一起的超媒体容器。

它不是博客：文章只是它承载的媒介档位之一。它更像一个可以持续加功能的软件产品。

## 技术架构

- **框架**：Astro 5（islands 架构 + MDX 内容集合）
- **交互岛屿**：Svelte 5（runes）
- **滚动叙事**：GSAP ScrollTrigger
- **样式**：Tailwind CSS v4 设计 token
- **部署**：Cloudflare Pages，未来将由 Workers + D1 承载账户与个性化能力

想知道它是怎么工作的？读一读[这个网站是如何工作的](/stories/how-this-site-works)——那篇故事本身就是全部媒介组件的现场演示。
